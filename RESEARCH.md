# Предсказание растворимости молекул по дескрипторам

Суть исследования. Техническое устройство и запуск — в `README.md`,
план по этапам — в `PLAN.md`.

## Научный вопрос
Насколько точно простая линейная модель предсказывает растворимость молекулы в воде
(log S) по пяти базовым дескрипторам: молекулярная масса, logP, число доноров и акцепторов
водородной связи, число колец.

## Смысл и ценность
Растворимость — одно из ключевых свойств при отборе кандидатов в лекарства. Если простая
модель даёт приемлемую точность, её можно использовать как быстрый фильтр до дорогих
расчётов и экспериментов, а также как бейзлайн для более сложных моделей.

## Данные
`data/molecules.csv` — 120 молекул, для каждой пять дескрипторов и измеренная
растворимость `log_solubility`. Разбиение: 80% обучающая выборка, 20% тестовая,
случайное, с фиксированным сидом. Пропусков и повторяющихся молекул нет (проверено при
сборке датасета). Тестовая выборка используется **только один раз** —
для итоговой оценки модели.

## Методы
Линейная регрессия с L2-регуляризацией (Ridge); признаки стандартизуются
(`StandardScaler`, обучается только на обучающей выборке). Гиперпараметр `alpha` подбирается
кросс-валидацией (5 фолдов) на обучающей выборке; до подбора модели сравниваются только
по кросс-валидации, тестовая выборка не используется. Итоговая метрика — RMSE выбранной
модели на тестовой выборке. Бейзлайн — предсказание средним значением обучающей выборки.
