# Растворимость молекул

Техническое описание проекта: как он устроен и как его запустить.

## Устройство
- `data/molecules.csv` — датасет.
- `src/train.py` — обучение и оценка модели.
- `requirements.txt` — зависимости с версиями.

## Как запустить / воспроизвести
```
pip install -r requirements.txt
python src/train.py
```

## Документы проекта
- `RESEARCH.md` — суть исследования: вопрос, ценность, данные, методы.
- `PLAN.md` — план реализации по этапам и шагам.

Файлы `RESEARCH.md` и `PLAN.md` обязательны: на их имена опирается система.
Не переименовывайте их.
